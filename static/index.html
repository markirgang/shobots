📖 Shobots Master Fleet Operating Manual & Instructions

Central management guide for controlling all robot project servers, configuring network combinations, and operating multimodal AI UIs.

Step 1

🚀 Launch & Control Robot Fleet Servers

  • Start All Servers: Click 🚀 Start All in the header to spin up all configured robot app background processes (Rover, Hexapod, Arm, Birds, Fish, Drones, Tweedpump).
  • Individual Control: Use individual ▶ Start and ⏹ Stop buttons on each robot card.
  • Launch All Web Pages: Click 🌐 Launch All Pages to open each robot's web UI in separate browser tabs.
Step 2

⚙️ Customize Combination Settings

  • Configure Folder Path & IP/Port: Click ⚙️ Configure Combination on any robot card to customize its root directory, IP address binding, or HTTP port.
  • Live Restart: Saving changes automatically restarts that specific robot server with its new parameters.
  • Reset Defaults: Click ↺ Reset Defaults anytime to restore factory default directories, IP hosts, and ports.
Step 3

🌐 Interactive Live Frame Switcher

  • Embedded Live Control: Click 🌐 Open Switcher or click any robot tab at the top bar to load its full 3D interactive web page directly inside Shobots.
  • Quick Actions: Use 🔄 Reload Frame or ↗️ Open in New Tab to manage embedded web previews seamlessly.
  • Realtime Status: The status pills continuously ping each server to verify health.
Step 4

🔌 Master Pinout & Hardware Matrix

  • Raspberry Pi GPIO Pinout: Navigate to 🔌 Master Wiring & Pinout view to review the complete 40-pin GPIO pinout matrix.
  • I2C Bus & Addresses: Review I2C address allocations (0x40 for Arm/Birds/Fish, 0x41 for Hexapod).
  • L298 Drivers & Motors: Check GPIO PWM assignments for DC motor drivers, relays, and ultrasonic sensors.
Step 5

🤖 Gemini AI Multimodal Agent

  • API Key Entry: Supply your Google Gemini API key in any connected robot UI's settings panel.
  • Voice Commands: Activate microphone for hands-free natural language robot control and dancing routines.
  • Multimodal Vision: Use camera feeds with Gemini vision model for realtime scene analysis and object detection.
Step 6

🛡️ Safety & System Maintenance

  • Shutdown All: Click 🛑 Close All Servers before powering down hardware.
  • Power Supply: Ensure high-current UBEC 5V power supply grounds are common with Raspberry Pi GND.
  • Emergency Stop: Use individual project emergency stop buttons if motor stall or collision occurs.
